# PWF Artifact

用户调用本技能时，保存其明确指定的文本、代码、图表或现有文件。根据当前对话确定产物的完整内容；指代不清时先请用户指出具体内容。

1. 用 `planning-with-files` 选定或新建本任务的计划，记为 `<PLAN_DIR>`；被别的流程调用时沿用它已选的计划。
2. 将产物写入 `<PLAN_DIR>/artifacts/`。用户指定文件名或格式时沿用；否则用简短主题命名，按下列规则选格式：
   - 文档、整理、报告类文本默认 `.html`：单文件、可直接在浏览器打开，样式内联，不依赖外部资源，支持浅色/深色和窄屏，长表格可横向滚动。
   - 代码片段使用其语言对应的扩展名。
   - 现有文件保留扩展名和原始字节。

   目标路径必须位于该目录内；同名时追加数字后缀，不覆盖已有文件。如果产物已在当前计划目录中，沿用原路径。
3. 在 `<PLAN_DIR>/progress.md` 记录产物路径和一句用途。确认保存后的内容与原产物一致；HTML 产物用 `open` 打开。向用户返回最终的绝对路径。
