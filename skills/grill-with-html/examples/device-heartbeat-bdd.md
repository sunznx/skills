## 设备与心跳

### 验收概览

```kv cols=2
验收范围: 设备运行、心跳、故障恢复与清理
目标环境: 目标 Lab
证据状态: 待执行
```

**系统与角色**：设备管理负责保存记录和管理运行实例。管理员使用 Admin 或 Lab CLI；Stats 接收心跳。运行时和中继分别提供实例与连接观测。

**共用数据**：在隔离环境建档国内设备 `D1` 和同区对照设备 `D2`。运行时按设备和本轮标识查询。心跳场景使用配置周期 `T`；`2T` 是建议的测试窗口，不是生产承诺。

### 状态索引

```state LR
已关机 -> 启动中: 开机
启动中 -> 运行中: 实例就绪
运行中 -> 失败: 实例意外退出
失败 -> 启动中: 手动重试
运行中 -> 停止中: 关机
停止中 -> 已关机: 停止确认
已关机 -> [*]: 确认删除
```

```state LR
正常上报 -> 暂停上报: 暂停心跳
暂停上报 -> 正常上报: 恢复心跳
```

状态图索引本例覆盖的转换。接口字段由实际 `api` 契约维护；本例不假定接口路径。

### 正常行为

#### D01 开机后关窗不关机

```kv cols=2
Given · 前置: Admin 选择国内。D1 已建档、已关机，没有运行实例。
When · 操作: 管理员从 Admin 开机，等实例就绪后关闭浏览器窗口。
```

**Then**：国内仍有 `D1`，海外列表没有。关窗前后均只有一个存活实例，ID 相同。

**验证入口**：Lab CLI 双区回读；Docker 或 Kind 按本轮标识比较实例。

**证据 · 待执行**：保留关窗前后实例快照和双区查询结果。

#### D02 暂停只影响心跳

```kv cols=2
Given · 前置: D1 正常上报心跳。记录实例 ID 和周期 T。若验中继，先建立独立连接并记录其 ID。
When · 操作: 管理员在 Admin 暂停 D1 的心跳，不执行关机。
```

| Then · 观察点 | 通过条件 | 验证入口 |
| --- | --- | --- |
| 心跳 | 暂停前发出的心跳结清。随后 `2T` 内没有该实例的新心跳。 | 核对 Admin 暂停回执，从结清时的 Stats 游标回读。 |
| 运行实例 | 原实例仍在运行，实例 ID 不变。 | Docker 或 Kind 按本轮标识查询。 |
| 中继连接（若纳入范围） | 探针通过原连接收发，无须重连。 | 核对两端连接 ID 与探针结果。 |

**证据 · 待执行**：保留暂停回执、Stats 查询与实例快照。验中继时另附探针结果。

#### D03 恢复触发首次上报

```kv cols=2
Given · 前置: D1 仍用原实例运行，心跳已暂停。记录 Stats 游标与下次周期发送时间。
When · 操作: 管理员恢复 D1 的心跳。
```

**Then**：原游标之后，下一周期前只收到一条该实例的新心跳。到下一周期再收到一条。实例 ID 未变。

**验证入口**：基于恢复回执与测试时钟回读 Stats 游标，并用运行时查询核对实例 ID。没有可控时钟时，先确认等效的观察窗。

**证据 · 待执行**：保留恢复回执、首条与下一周期事件的时间及实例 ID。可用观察窗待确认。

### 失败与恢复

#### D04 实例异常退出可见

```kv cols=2
Given · 前置: D1 和 D2 均在运行。按实例 ID 确认故障只作用于 D1。
When · 操作: 在测试环境让 D1 的实例意外退出，不发出关机请求。
```

| Then · 观察点 | 通过条件 | 验证入口 |
| --- | --- | --- |
| 运行实例 | D1 的原实例确实退出。 | 运行时的退出记录。 |
| 设备记录 | 同一个 `D1` 在约定时限内变为失败，而非已关机。 | Admin 设备回读。观测时限待确认。 |
| 对照设备 | `D2` 的实例 ID 与存活状态不变。 | 运行时按 `D2` 查询并与基线比较。 |

**证据 · 待执行**：保留退出记录、设备查询与对照快照。

#### D05 手动重试复用设备记录

```kv cols=2
Given · 前置: D1 处于失败状态，旧实例已退出。解除故障并保留旧实例 ID。
When · 操作: 管理员对 D1 发起一次手动重试。
```

**Then**：能回读同一个 `D1`，没有新增记录。本轮唯一存活实例的 ID 与旧实例不同。实例就绪后，`D1` 才显示运行中。

**验证入口**：Admin 与 Lab CLI 回读设备；运行时查存活实例与就绪记录。

**证据 · 待执行**：保留重试回执、设备列表差异和新旧实例 ID。

### 关停与清理

#### D06 关机回收实例，保留设备

```kv cols=2
Given · 前置: D1 运行中。记录设备 ID 和实例 ID。D2 仍在运行，作为对照。
When · 操作: 管理员对 D1 发出关机请求。
```

**Then**：`D1` 显示已关机时，原实例已退出，且按本轮标识查不到运行实例。设备 `D1` 保留；`D2` 的实例 ID 与存活状态不变。

**验证入口**：对照 Admin 状态与运行时停止记录。用 Lab CLI 回读 `D1`，并在运行时按 `D2` 查对照实例。

**证据 · 待执行**：保留停止与状态变更时间、设备回读和对照实例快照。

#### D07 删除只清理本轮资源

```kv cols=2
Given · 前置: D1 已关机但仍可查。列出本轮待清理资源和不得删除的 D2 对照资源。
When · 操作: 管理员确认删除 D1 的设备记录。
```

| Then · 观察点 | 通过条件 | 验证入口 |
| --- | --- | --- |
| 设备记录 | 用原 ID 查不到 `D1`。 | Admin 和 Lab CLI 按原 ID 回读。 |
| 本轮资源 | 待清理清单上的项目均无残留。 | 按本轮归属查询资源，与清单逐项核对。 |
| 对照资源 | `D2` 仍可回读，对照资源的 ID 和状态不变。 | Lab CLI 设备回读和对照资源清单。 |

**证据 · 待执行**：保留删除回执、前后资源清单和 `D2` 快照。

### 证据边界

Cloud 原审阅稿提到本机 Docker 或 Kind 生命周期证据，以及 `managed-simulator` 的 Stats 与实例保持观察。本示例未复核原始回执。它们不等于目标 Lab 通过，也不能替代对原中继连接连续性的独立验证。
